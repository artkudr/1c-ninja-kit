# Companions (внешние бинарники)

`1c-ninja-mcp` и `NinjaLive` — **не** companions: они лежат в kit (`components/`, `project-scaffold/cfe/`).

Здесь только то, чего нет в репозитории:

| Pin | Назначение |
|-----|------------|
| bsl-analyzer.exe | MCP semantics |
| MCP_Toolkit.epf | fallback live на :6003 |
| Apache tools dirs | публикация web / ninja-live |

См. `pins.json` и `install/path-defaults.windows.yaml`.
