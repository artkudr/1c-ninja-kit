# Versioning

| Что | Схема |
|-----|--------|
| Kit product | semver `0.1.0` → `0.2.0` → `0.3.0` (`VERSION`, `manifest.yaml`) |
| CFE / EPF в клиентских проектах | `X.Y.Z.W` по скиллу `1c-versioning` |
| Profile lock | `lock/profile.lock.json` (names hash) |

Не смешивать semver kit с версией расширения NinjaLive.
