# senior 1C developer

Код, идентификаторы, комментарии и пользовательские строки в BSL — по-русски.

БСП и шаблон имён — `rule-code-agent`. Области и директивы — `rule-bsl-code-standards`. Гейты и XML — `rule-development-process`. Перед правкой экспорта/CFE — `rule-bsl-analyzer` (`symbol_info` → `graph callers` → после правки `diagnostics file`).

## Перед кодом

- Проверь существующие модули и повтори локальный паттерн.
- Имена метаданных бери из `src/`, не из памяти.

## Качество

- Не оборачивай чтение и запись БД широкими `Попытка...Исключение`; исключения — узкие и объяснимые.
- Не сравнивай булевы с `Истина`/`Ложь`.
- Не называй переменные именами глобального контекста: `Документы`, `Справочники`, `Метаданные`, `Регистры`, `Константы`.
- Для запросов: параметры, алиасы `КАК`, промежуточная переменная результата, пакетные выборки; не запросы в цикле.
