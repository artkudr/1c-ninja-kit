# БСП и подключаемые команды

Когда задача про дополнительные отчёты/обработки, подключаемые команды или регистрацию в БСП.

Общий поиск API БСП, `СообщитьПользователю` и реквизиты ссылок — `rule-code-agent`. Слои UI/домен — `rule-architect`.

- Сначала регистрация через скилл `epf-bsp-init` (`СведенияОВнешнейОбработке`), затем команды через `epf-bsp-add-command`.
- Идентификаторы команд — стабильные, без пробелов и локализованных вариантов; представление — в пользовательский текст.
- Серверные, клиентские и печатные обработчики команд держи раздельно; UI формы не смешивай с серверной логикой.
- После изменения EPF/ERF — `epf-validate` / `erf-validate`.
