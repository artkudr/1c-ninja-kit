# 1С:Фреш — средства адаптации

Применяй, когда задача связана с публикацией во Фреш, аудитом расширения/обработки, безопасным режимом, профилями безопасности, комплектом поставки EPF/ERF или загрузкой CFE в сервис.

## Обязательно

1. Прочитай и следуй скиллу `{{SKILLS_ROOT}}\skill-fresh-adaptation\SKILL.md`.
2. Для расширений (CFE) — дополнительно `{{SKILLS_ROOT}}\skill-fresh-cfe-audit\SKILL.md`.
3. Для доп. отчётов/обработок (EPF/ERF) — дополнительно `{{SKILLS_ROOT}}\skill-fresh-epf-audit\SKILL.md` и при регистрации БСП — правило `rule-bsp-developer`.
4. Проверки выполняй через скиллы валидации проекта (`cfe-validate`, `epf-validate`, `erf-validate`) и поиск по исходникам. Не правь XML метаданных напрямую.
5. В конце ответа **всегда** выведи отдельный блок «НУЖНА РУЧНАЯ НАСТРОЙКА» по `{{SKILLS_ROOT}}\skill-fresh-adaptation\manual-steps.md` — даже если автопроверки зелёные. XML — только скиллы (`rule-development-process`).

## Не делать

- Не заявляй «готово к Фреш», пока не пройден чеклист соответствующего скилла.
- Не пропускай ручные шаги (ЛК, разрешения при загрузке, тест без АдминистраторСистемы, комплект поставки).
