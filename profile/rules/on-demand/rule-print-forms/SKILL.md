# Печатные формы: сетка и данные, а не картинка

Грузи на любой задаче с макетом MXL, печатной формой, PDF-образцом или «сделай как в образце».

## Главное правило

Печатная форма — это **данные и сетка**. Картинка допустима только там, где объект не является текстом, линией или заливкой: логотип, слоган, оттиск печати, факсимиле, подпись, QR.

Образец нужен, чтобы снять **геометрию и стиль** (ширины, высоты, цвета, шрифты, отступы), а не чтобы вырезать из него блоки. «Точь-в-точь» достигается числами и ячейками, а не растром.

## Что чем делается

| Элемент образца | Инструмент |
|---|---|
| Заголовки, реквизиты, адреса, подписи, «Итого», «Всего», текст в полосах | Ячейка: `text` / `param` + шрифт |
| Бежевая плашка шапки, тёмная нижняя полоса, цветная строка | Ячейка/строка: `backColor` + высота строки |
| Тонкая оранжевая/жёлтая линия над полосой | Граница ячейки: `topBorder` / `bottomBorder` + `borderColor` |
| Шапка таблицы (№, Товар, Кол-во, Цена, Сумма) | Строка с `rowStyle`: жирный шрифт, `backColor`, `border: Solid` |
| Линии таблицы, рамки банковских реквизитов | Границы ячеек, не рисунок |
| Итоги и суммы | Ячейки с `param`, выравнивание вправо |
| Логотип и фирменный знак (слоган — только если он часть знака), печать, факсимиле, подпись | Картинка: `pictures`/`drawings` в макете или `ВывестиРисунок` в коде |
| QR | Генерировать из строки (URL), не вырезать из образца |
| Поля, ориентация, масштаб | `printSettings`, а не пустые картинки-отступы |

## Как разбирать растровый образец

1. Сними числа: ширины колонок, высоты строк, отступы, цвета, кегли, начертания. Для скриншота — `img-grid`; для живой формы — `getBoundingClientRect`.
2. Выпиши тексты из образца и перенеси их в ячейки. Если текст выделяется/копируется в PDF — это текст, а не картинка.
3. Вырежи только фирменные растры: логотип, слоган, оттиск, факсимиле, подпись. Всё остальное — пересборка.
4. Проверь, меняется ли блок от данных (наименование, адрес, сумма, дата, число строк). Если да — это ячейки и параметры; картинка не обновится.
5. QR не вырезай: сгенерируй из URL с нужным размером и коррекцией.

## Типовые куски макета

Шапка-плашка и строка реквизитов:

```json
"styles": {
  "плашка": { "backColor": "#F4EEE6", "verticalAlignment": "Center", "textPlacement": "Wrap" },
  "реквизиты": { "font": "default", "horizontalAlignment": "Center", "verticalAlignment": "Center", "textColor": "#333333", "textPlacement": "Wrap" }
}
```

```json
{ "height": 32, "rowStyle": "плашка" },
{ "height": 60, "cells": [{ "span": 10, "style": "реквизиты", "param": "Реквизиты" }] }
```

Шапка таблицы:

```json
"шапка-таблицы": { "font": "жирный", "horizontalAlignment": "Center", "verticalAlignment": "Center", "backColor": "#EDE8E1", "border": "Solid", "borderColor": "#333333", "textPlacement": "Wrap" }
```

```json
{ "height": 64, "rowStyle": "шапка-таблицы", "cells": ["№", "Товар", ">", ">", ">", "Кол-во", "Ед.", "Цена", "Сумма", ">"] }
```

Нижняя полоса с тонкой линией сверху:

```json
"полоса": { "backColor": "#233B35", "textColor": "#FFFFFF", "verticalAlignment": "Center", "topBorder": { "style": "Solid", "width": 2 }, "borderColor": "#F59D55" }
```

```json
{ "height": 176, "rowStyle": "полоса", "cells": [
  { "span": 3, "style": "полоса", "param": "Наименование" },
  { "span": 3, "style": "полоса", "param": "ТелефонСайт" },
  { "span": 3, "style": "полоса", "param": "Почта" },
  { "style": "полоса", "pictureParameter": "QR" }
] }
```

Картинки — только настоящие растры. В коде они кладутся поверх пустых ячеек с тем же фоном, `РазмерКартинки = Пропорционально`, без рамок; фон прямоугольника обязателен, прозрачной заливки в 8.3 нет.

## Антипаттерны

- Вырезать бежевую плашку шапки и вставить её картинкой.
- Вырезать тёмную нижнюю полосу с оранжевой линией и вставить картинкой.
- Вырезать шапку таблицы (№, Товар, …) и ставить её растром.
- Класть скриншот всего образца фоном страницы.
- Вырезать текстовый блок «чтобы было похоже»: он не масштабируется, не ищется, не переводится и не меняется с данными.
- Вставлять слоган или реквизиты картинкой, если это обычный текст, а не часть фирменного знака.
- Брать QR из образца 91×91 px и растягивать.
- Оставлять у картинки рамку или белый прямоугольник на цветной плашке.

## Приёмка печатной формы

- `ТабличныйДокумент.Рисунков` равно числу настоящих растров (в этой форме — 5: логотип, слоган, печать, факсимиле, QR). Больше — значит, в макет попал кусок текста или фона.
- В PDF текст шапки, шапки таблицы и нижней полосы извлекается как текст; картинки не перекрывают текст.
- Цвета полос и линий совпадают с образцом, геометрия — в допуске из приёмки.
- Один эталон на задачу: новый круг не снимает новый «до».
- Если правил растровый образец — в артефакте перечислены вырезанные файлы и их назначение. Всё, что не в списке, — ячейки.
