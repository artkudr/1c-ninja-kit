# Перенос предопределённых элементов без потери id

Операция меняет только положение узла `<Item>` в `Ext/Predefined.xml`. Идентификатор
`id`, код, наименование и вложенные элементы сохраняются. Это важно: удаление и
повторное добавление элемента меняет `id` и рвёт связь с данными в информационной базе.

## Когда применять

- Нужно перенести существующий предопределённый элемент в другую папку.
- Нужно перенести папку вместе с вложенными элементами.
- Нужно вернуть элемент из папки в корень.

Не применять:

- для **новых** элементов — `meta-edit add-predefined`;
- для переименования, смены кода или удаления — это отдельные операции, здесь их нет;
- для правки `Predefined.xml` руками — правило запрещает.

## Команда

```powershell
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/move-predefined.ps1" `
  -ObjectPath "<объект>" -Move "Элемент >> Папка"
```

`-ObjectPath` — каталог объекта (`Catalogs/Имя`) или его XML-файл (`Catalogs/Имя.xml`).

Inline-формат: `Элемент >> Папка`, несколько переносов через `;;`.
В корень: `Элемент >> /`.

```powershell
# Один перенос
-Move "ОрганизацияДляОтгрузкиНаЗамену >> ОтгрузкаНаЗамену"

# Пачкой
-Move "СкладДляОтгрузкиНаЗамену >> ОтгрузкаНаЗамену ;; ОрганизацияДляОтгрузкиНаЗамену >> ОтгрузкаНаЗамену"

# Вернуть в корень
-Move "СтараяНастройка >> /"
```

JSON — те же поля, можно смешивать с будущими операциями:

```json
{
  "moves": [
    { "item": "СкладДляОтгрузкиНаЗамену", "folder": "ОтгрузкаНаЗамену" },
    { "item": "ОрганизацияДляОтгрузкиНаЗамену", "folder": "ОтгрузкаНаЗамену" },
    { "item": "ВКорень", "folder": null }
  ]
}
```

Поддерживаются также обёртки `{ "move": { "predefined": [...] } }` и просто массив.
Вместо `folder` можно писать `into`; `null`, `""` или `"/"` означают корень.

## Что делает скрипт

1. Находит `Predefined.xml` по объекту.
2. Ищет элемент по `Name` на любом уровне и папку по `Name` с `IsFolder = true`.
3. Переносит узел в `ChildItems` папки, сохраняя `id` и всё поддерево.
4. Переиндентирует только перенесённый узел, остальной файл не трогает.
5. Убирает опустевший `<ChildItems>` — платформа такой тег не пишет.
6. Сохраняет UTF-8 BOM, переводы строк исходника и канонический вид `/>`.
7. Запускает `meta-validate`, если он найден; `-NoValidate` отключает проверку.

Имена элементов и папок в `Predefined.xml` уникальны. Если скрипт встретит дубль,
он остановится с ошибкой, а не выберет первый попавшийся узел.

## Ограничения

- Перенос папки в саму себя или в своего потомка запрещён.
- Элемент, который уже лежит в целевой папке, пропускается с сообщением.
- Скрипт не меняет `Name`, `Code`, `Description` и `IsFolder`.
- Если перенести все элементы из файла, останется пустой `Predefined.xml`; это
  допустимо, но такой файл лучше проверить глазами.

## Проверка

```powershell
# После переноса
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/move-predefined.ps1" `
  -ObjectPath "src/cfe/Расширение/Catalogs/Справочник" -Move "Элемент >> Папка"
```

Ожидаемо: в выводе `Moved predefined ...`, в конце `=== Validation OK ===`,
у перенесённого узла прежний `id`.
