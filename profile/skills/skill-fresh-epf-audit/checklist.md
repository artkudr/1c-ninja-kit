# Чеклист EPF/ERF → 1С:Фреш

`B` = Blocker, `W` = Warning, `M` = ручной шаг.

## Регистрация БСП

- [ ] Есть `СведенияОВнешнейОбработке()` (`B`)
- [ ] `БезопасныйРежим = Истина` (`B`)
- [ ] Вид / назначение / команды соответствуют замыслу (`B`)
- [ ] Для назначаемых — указаны объекты назначения (`B`)
- [ ] Идентификаторы команд стабильные, без локализации в id (`W`)
- [ ] `epf-validate` / `erf-validate` без ошибок (`B`)

## Безопасный режим

- [ ] Нет COM (`B`)
- [ ] Нет `Выполнить` / `Вычислить` (`B`)
- [ ] ВК только из конфигурации; иначе разрешение + доступность в CF (`B`)
- [ ] Нет произвольной ФС / приложений ОС / серверной криптографии (`B`)
- [ ] Temp через `ПолучитьИмяВременногоФайла` + удаление (`B`)
- [ ] Нужные `РазрешениеНа…` объявлены в сведениях (`B`)
- [ ] Интернет: разрешения и/или подтверждение пользователя (`B`/`M`)

## Обращения и формы

- [ ] Нет `ВнешняяОбработка.<Имя>` / `ВнешнийОтчет.<Имя>` (`B`)
- [ ] Полное имя берётся из `Метаданные().ПолноеИмя()` (`B`)
- [ ] Дочерние формы открываются через вычисленное полное имя (`B`)
- [ ] Веб-клиент ок или есть уведомление об ограничении (`B`)

## Поведение и качество

- [ ] Длительные операции ≥10 с через БСП (`B`/`W`)
- [ ] Нет универсальных опасных утилит порчи данных (`B`)
- [ ] Не копируется лишний типовой код (`W`)
- [ ] Оптимальность запросов (`W`)
- [ ] Ошибки в исключении не скрываются полностью (`W`)
- [ ] Нет пароля на модули / обфускации (`B`)

## Поставка и тест

- [ ] Версия в реквизитах регистрации корректна при обновлении (`B`/`M`)
- [ ] Скачан помощник из ЛК, собран zip (файл + манифест) (`M`)
- [ ] Разделы/объекты назначения выбраны (для нескольких CF — пересечение) (`M`)
- [ ] Тест через интерфейс БСП, не «Файл — Открыть» (`M`)
- [ ] Тест без `АдминистраторСистемы`, тонкий + веб (`M`)
- [ ] Отправка на аудит через ЛК / обслуживающую организацию (`M`)
