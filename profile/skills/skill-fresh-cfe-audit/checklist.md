# Чеклист CFE → 1С:Фреш

Отмечай при аудите. `B` = Blocker, `W` = Warning, `M` = ручной шаг пользователя.

## Метаданные и свойства

- [ ] Уникальное имя расширения (`B`)
- [ ] Версия расширения задана и осмысленна при обновлении (`B`)
- [ ] Режим совместимости согласован с основной CF (`B`/`W`)
- [ ] `cfe-validate` без ошибок (`B`)
- [ ] Префиксы собственных объектов/методов соблюдены (`W`, стиль)

## Безопасный режим и разрешения

- [ ] Нет опоры на отключённый безопасный режим (`B`)
- [ ] Нет COM, приложений ОС, произвольной ФС, чужих ВК, серверной криптографии (`B`)
- [ ] Temp-файлы только через `ПолучитьИмяВременногоФайла` + удаление после использования (`B`)
- [ ] Список нужных разрешений при загрузке сформирован для пользователя (`M`)
- [ ] Исходящие ресурсы (URL) перечислены явно (`B`/`M`)

## Данные и обмен

- [ ] Если меняется структура данных — объекты в `МиграцияПриложений` (`B`)
- [ ] Авторегистрация в `МиграцияПриложений` выключена (`B`)
- [ ] Признак изменения при подключении расширения установлен (`B`)
- [ ] Целевые конфигурации сервиса поддерживают data-расширения (`M`/`W`)

## Код и поведение

- [ ] Нет пароля на модули / обфускации (`B`)
- [ ] Длительные операции ≥10 с через БСП (`B`/`W`)
- [ ] Нет отключения штатных проверок через `ОбменДанными.Загрузка` без причины (`W`/`B`)
- [ ] В `Попытка…Исключение` не глотается текст ошибки без следа (`W`)
- [ ] Не копируется лишний типовой код — вызывается API (`W`)
- [ ] Нет универсальных «опасных» утилит порчи данных (`B`)
- [ ] Запросы без типичных антипаттернов (ИЛИ, точка от составного типа, тяжёлые подзапросы) (`W`)

## Клиенты и роли

- [ ] Веб-клиент работает или есть корректное уведомление об ограничении (`B`)
- [ ] Ключевой функционал без обязательного расширения работы с файлами (`W`)
- [ ] План теста без роли `АдминистраторСистемы` описан пользователю (`M`)

## Поставка

- [ ] Выгрузка `.cfe` (`M`)
- [ ] Описание, логотип 64×64, скриншоты (`M`)
- [ ] Загрузка в ЛК + разрешения + аудит (`M`)
