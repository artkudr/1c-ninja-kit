# Аудит доп. отчёта/обработки (EPF/ERF) для 1С:Фреш

Вызывается из `1c-fresh-adaptation` или напрямую. Чеклист: [checklist.md](checklist.md). Ручные шаги: [../1c-fresh-adaptation/manual-steps.md](../1c-fresh-adaptation/manual-steps.md) (разделы «Общие» + «Только EPF/ERF»). Регистрацию БСП делай по правилу `bsp-developer` и скиллам `epf-bsp-init`/`epf-bsp-add-command`.

## Алгоритм

1. Найти XML-исходники EPF/ERF в workspace (каталог `src/epf`, `src/erf` или путь, который указал пользователь).
2. `epf-validate` / `erf-validate` — структура исходников.
3. Проверить модуль объекта:
   - есть экспортная `СведенияОВнешнейОбработке()`;
   - `ПараметрыРегистрации.БезопасныйРежим = Истина` (или эквивалент «Безопасный»);
   - вид обработки, назначение, таблица команд согласованы с замыслом;
   - при необходимости — разрешения через `РаботаВБезопасномРежиме.РазрешениеНа…`.
4. Если регистрации нет — сначала `epf-bsp-init`, команды — `epf-bsp-add-command`, затем снова validate.
5. Поиск в коде:
   - запрещённые операции безопасного режима (COM, ФС, ОС, чужие ВК, `Выполнить`/`Вычислить`);
   - обращения `ВнешняяОбработка.<Имя>` / `ВнешнийОтчет.<Имя>` → заменить на `РеквизитФормыВЗначение(...).Метаданные().ПолноеИмя()`;
   - длительные операции → БСП;
   - интернет без разрешений и без подтверждения пользователя.
6. Имена форм: не зашивать полные имена жёстко — в сервисе имя подключения другое.
7. Сформировать отчёт оркестратора + **НУЖНА РУЧНАЯ НАСТРОЙКА** (помощник zip-комплекта обязателен).

## Жёсткие требования (Blocker)

- Соответствие подсистеме БСП «ДополнительныеОтчетыИОбработки».
- `БезопасныйРежим = Истина` в сведениях о внешней обработке.
- Нет COM; ВК только из состава целевой конфигурации.
- Нет стороннего исполнения кода вне конфигурации.
- Нет паролей на модули / обфускации.
- Нет обращений к обработке по фиксированному имени метаданных.
- Универсальные опасные обработки изменения данных — отказ аудита.

## Разрешения (допустимо запросить)

Через API БСП в `СведенияОВнешнейОбработке` (пример — демо `_ДемоЗагрузкаНоменклатурыИзПрайсЛистаПрофилиБезопасности`):

- `РазрешениеНаИспользованиеВнешнейКомпоненты`
- `РазрешениеНаИспользованиеИнтернетРесурса`
- `РазрешениеНаИспользованиеКаталогаВременныхФайлов`
- `РазрешениеНаИспользованиеПривилегированногоРежима`
- и родственные `РаботаВБезопасномРежиме.РазрешениеНа…`

Если адреса интернет заранее неизвестны и есть формы — запрашивать подтверждение у пользователя перед отправкой; для безформенных/регламентных — по умолчанию не выполнять опасную операцию на сервере без явной команды с формой подтверждения.
