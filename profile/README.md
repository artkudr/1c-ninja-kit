# Profile SoT

Канон skills / rules / agents для поставки. Deploy → `%USERPROFILE%\.cursor\`.

- Агрегат: `profiles/1c-ninja-kit.yaml`
- Packs: `packs/*/manifest.json` (навигация; полный снимок лежит в `skills|rules|agents`)
- Docs: `%USERPROFILE%\.config\opencode\docs\` (локальные патчи — скилл `cursor-local-patches`)

Обновление SoT: явный capture (v0.2), не silent sync из живого профиля.
