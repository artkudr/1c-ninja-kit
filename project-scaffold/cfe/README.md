# NinjaLive (эталон)

Полная копия эталона из `ecoladev/src/cfe/NinjaLive` на момент snapshot kit.

| Поле | Значение |
|------|----------|
| Пара MCP | `components/1c-ninja-mcp` |
| RootURL | `ninja-live` |
| Назначение | live HTTP API ИБ + `live_extensions_list` |

Загрузка в ИБ: `db-load-xml -Extension "NinjaLive" -UpdateDB` (bootstrap-расширение, вне хранилища).
