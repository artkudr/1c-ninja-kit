# /opsx-explore

Режим исследования: думать, читать код/метаданные, уточнять требования. **Не писать прикладной код.**

Артефакты OpenSpec (proposal/design/specs) — можно создавать/обновлять, если пользователь просит зафиксировать мысль.

## Stance

Любопытство, диаграммы, опора на реальный codebase (MCP first). Не форсировать propose.

## Start

1. Список активных `openspec/changes/` (кроме archive).
2. При упоминании change — прочитать его артефакты.
3. Факты 1С — через MCP, не из памяти.

## End

Можно предложить `/opsx-propose`, обновить артефакт или просто зафиксировать ясность. Авто-capture без согласия — нет.
